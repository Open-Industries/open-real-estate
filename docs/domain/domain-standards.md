# Domain Standards — Real Estate

Alignment mapping for this core. *Aligned to* throughout: conveyancing law, notarial
acts and official land registration remain with licensed professionals and registries.

## Concept mapping

| Platform concept | Domain standard | Mapping |
|---|---|---|
| Properties & rights posture | ISO 19152 (LADM) | Registry follows LADM party/right/parcel thinking; official registration stays with the land registry |
| Listing data | RESO Data Dictionary | Property field posture for MLS-style interoperability |
| Areas | ISO 9836 | Floor-area measurement posture |
| Escrow | Closing practice | Guarded escrow accounts; the no-overrun invariant; append-only releases |

## Scope boundaries

This core does not register titles, execute deeds or hold client money as a regulated
escrow agent; it is the platform brokerages integrate with regulated parties.
